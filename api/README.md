# TypeSpec Definitions for Tailscale API

This folder contains TypeSpec definitions for Tailscale's API.
When this was implemented, Tailscale only had a markdown-based
documentation of their APIs. So this was created to generate
an OpenAPI spec from TypeSpec definitions.

Since this was written, Tailscale has upgraded their docs to
generated API docs using [scalar.com](https://scalar.com).

I've decided to leave this in place for the time-being
because the API spec generated by Scalar has errors,
like most auto-generated ones do. The TypeSpec definitions
provide a deterministic way to generate the API spec.

I will re-evaluate this if the quality of the official
auto-generated API spec becomes better at some point.

## Development

- [Install](https://typespec.io/docs/) the TypeSpec
  compiler globally or run `make ensure` at the root
  of this repo.
- Install the TypeSpec language server for your IDE.
- Run `npm i` in this directory.

## Generate API Spec

You can either run `npm run compile` in this directory.
**OR**, you can run `make gen_openapi` from the root
of the repo.
